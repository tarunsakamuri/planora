## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/tarunsakamuri/planora.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Start Backend

```bash
cd backend
npm install
npm start
```
